Periphery memory currently ends at address `7`: `0..2` are UART, `3..4` map timer/custom interrupt devices to ISR slots, `5..6` store their priorities, and `7` is `timer_interrupt_interval`. Value `0` disables the timer interrupt; values `>0` enable it as the instruction interval, and writes to address `7` reset `timer_cnt`. The TUI periphery box now has only the `UART` and `Interrupts` pages, and the timer interrupt interval is shown on `Interrupts`.
