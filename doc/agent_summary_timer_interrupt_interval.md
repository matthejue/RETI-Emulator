Periphery address 8 is `timer_interrupt_interval`; value `0` disables the timer interrupt, and any value `>0` enables it as the instruction interval. The emulator defaults `interrupt_timer_interval` to `0`; `-I` sets that value and startup writes it into the mapped cell. Writes by guest code to address 8 update the interval and reset `timer_cnt`; the System Info TUI labels the cell and allows editing it while keeping `sram_max_address` read-only.
