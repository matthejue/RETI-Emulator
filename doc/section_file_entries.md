Assemble mode now requires a same-basename `.sections` file next to the `.reti` input. The `.sections` JSON must contain unsigned 32-bit integer entries in this layout:

```json
{
  "codesegment_start": 0,
  "datasegment_start": 4572,
  "stack_start": 8000
}
```

`-a/--assemble` writes these three values as the first three encoded 32-bit words in the generated `.bin`, before appending the encoded SRAM words from the loaded `.reti` program.

For normal execution without `-e`, `stack_start` also affects the autogenerated EPROM start program. `stack_start: -1` keeps the old behavior and places `SP` at the end of SRAM; any other value sets `SP` to that offset plus the SRAM address-space constant.
